- Realizado a partir dos conhecimentos obtidos na 'Imersão IA _ Alura com Google Gemini 2025' e através das tecnologias Google Colab, Google AI Studio e Google Gemini, este Projeto visa a construção de um ChatBot que gera instruções para realização de Exercícios Fisioterapêuticos.

- O ChatBot **Reabilita Fácil** é um projeto de comunicação, desenvolvido com o objetivo de fornecer instruções de reabilitação não supervisionada para pacientes que sofreram Acidente Vascular Cerebral (AVC). A iniciativa busca atender cuidadores familiares que enfrentam dificuldades no acesso à fisioterapia convencional, seja pela falta de serviços disponíveis no Sistema Único de Saúde (SUS), pela impossibilidade de deslocamento do paciente, ou pela ausência de recursos para custear atendimento domiciliar particular (HomeCare).
